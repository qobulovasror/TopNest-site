# TopNest site and extension catalog

This public repository contains only the static [TopNest website](https://qobulovasror.github.io/TopNest-site/) and its [extension catalog](https://qobulovasror.github.io/TopNest-site/extensions/). The macOS app is currently in private developer preview; a signed public download is being prepared.

See [EXTENSIONS.md](EXTENSIONS.md) for the widget package format and submission process. GitHub Pages publishes this repository's `main` branch from its root.
